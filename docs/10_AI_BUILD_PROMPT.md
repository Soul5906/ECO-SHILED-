# 10. Prompt for an AI Coding Assistant

Build and maintain the ECO-SHIELD full-stack application using the source code and documentation in this repository.

Rules:
1. Inspect the existing project before editing.
2. Preserve working behavior and avoid rewriting the entire codebase unnecessarily.
3. Implement only features that can be connected end-to-end.
4. Do not invent results, data, API responses, or test outcomes.
5. Keep frontend and backend API contracts consistent.
6. Add validation, error handling, loading states and tests with each feature.
7. Update documentation when commands, endpoints, data models, or behavior change.
8. Run available tests and builds; report exact outcomes.
9. If a command cannot be run, state that limitation.
10. Prefer small, verifiable changes and avoid unnecessary dependencies.
11. Never treat heuristic diagnosis scores as probabilities or confirmed causes.
12. Before finishing, list changed files, implemented behavior, test results, known issues, and the next recommended task.

When adding a feature, use this sequence:
- Inspect relevant files.
- State a short implementation plan.
- Implement the smallest complete end-to-end change.
- Add/update tests.
- Run relevant checks.
- Update documentation.
- Summarize results and limitations.
